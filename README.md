# DELTA FORCE META — k1t0

База META-сборок для **Delta Force Warfare 32×32 / PC / Steam Global**.

## Возможности
- поиск и фильтры по оружию;
- META-only;
- копирование кода сборки;
- статусы: проверен / не проверен / не работает;
- локальное сохранение проверок;
- кнопка обновления базы из внешнего источника.

> Проект сообщества и не связан с Team Jade / Tencent.
